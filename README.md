## 📖 Overview

A full-stack social media application with three clients — **web** (React), **mobile** (React Native), and a **Node/Express** server with real-time features (chat, media sharing, toxicity analysis, admin controls).

## 🏗 Architecture

```
social/
├── server/   # Node/Express + TypeScript backend
├── web/      # React web client
└── mobile/   # React Native mobile app
```

## ✨ Features

- 💬 Real-time chat & media sharing
- 🤖 Toxicity analysis (AI/ML)
- 🛡 Admin mediator controls, bulk admin actions

## 🛠 Tech stack

`React` · `React Native` · `Node.js` · `Express` · `TypeScript` · `MongoDB` · `WebSockets`

## 📦 Quick start

```bash
git clone https://github.com/m3rashid/social.git
cd social/server && yarn install && yarn dev
cd ../web && yarn install && yarn dev
cd ../mobile && yarn install && yarn dev
```
